Google Sheets Setup

Connect this website to a Google Spreadsheet as a CMS backend.

1

Create a Google Cloud Project

Go to console.cloud.google.com, create a new project, and enable the Google Sheets API.

2

Create a Service Account

In IAM & Admin → Service Accounts, create an account with role Editor. Under Keys, create a new JSON key and download it.

3

Create a Spreadsheet

Create a new Google Sheet with 6 tabs named exactly:
Products · Projects · Categories · Settings · Users · Enquiries
Share it with your service account email (Editor access).

4

Configure js/sheets-cms.js

Open the file and fill in SHEETS_CONFIG:

SPREADSHEET_ID: 'your-spreadsheet-id', SERVICE_ACCOUNT: { client_email: 'xxx@your-project.iam.gserviceaccount.com', private_key: '-----BEGIN RSA PRIVATE KEY-----\n...', }

⚠ Never commit your private key to a public repo. Use environment variables in production.

5

Initialise headers & seed data

Click the button below. It will write column headers to all tabs, then push all 100 products, 20 projects, categories and default settings into the sheet.
